## Design Context

### Users
Junior to senior developers (primarily Latin American market, Spanish-speaking). They use the platform in focused coding sessions on desktop — writing real software, running tests, progressing through guided submodules. The context is high-concentration work, not casual browsing. They expect a tool that treats them like professionals, not students.

**Emotional goals**: Confidence and quiet momentum. When tests pass, the moment should feel like warm acknowledgment — not a parade, not cold silence. Think Anthropic's tone: restrained but human. The user should feel *capable*, not *rewarded*.

### Brand Personality
**Bold. Firm. Avant-garde.**
Think Apple's precision meets Anthropic's intellectual clarity, with startup conviction. The platform should feel like a serious instrument for serious builders — not a gamified classroom. No Duolingo cuteness, no Coursera blandness.

### Aesthetic Direction
- **Theme**: Dark mode — developers in focused coding sessions, often at night
- **Primary accent**: Pure red (#ff0000) — bold, uncompromising, high-energy
- **Typography**: Sora (geometric body) + Bodoni Moda (editorial serif accents) + JetBrains Mono (code)
- **Anti-references**: Duolingo (too cute/gamified), Coursera (too bland/corporate), generic bootcamp sites
- **References**: Vercel dashboard (precision), Linear (craft), Stripe docs (clarity), Anthropic.com (intellectual elegance)
- **Success moments**: Subtle and warm. A gentle overlay with a clear next-step CTA, not confetti or fireworks. Auto-dismisses after a few seconds. Users who skip celebrations repeatedly get them disabled automatically.

### Accessibility
- **Primary concern**: Keyboard users. All workspace interactions must be fully keyboard-navigable (Ctrl+1/2/3 for panels, Ctrl+Enter to run, Ctrl+K command palette, Escape to dismiss).
- **Reduced motion**: Respect `prefers-reduced-motion`. Animations enhance but are not required for comprehension.
- **Contrast**: Dark theme requires careful attention — text-dim (#666) on bg (#131111) must remain readable. No critical information conveyed by color alone.

### Design Principles
1. **Precision over decoration** — every pixel earns its place. No ornamental flourishes.
2. **Hierarchy through restraint** — use size, weight, and space to guide the eye. Not color.
3. **Professional by default** — the UI should make users feel like engineers, not students.
4. **Bold accents, quiet surfaces** — the red accent hits hard because everything around it is calm.
5. **Typographic confidence** — the Bodoni Moda italic accents are the brand signature. Use them sparingly, let them command attention.
6. **Warm, not cold** — the precision of Apple, but never clinical. Completion moments acknowledge the human, not just the output.

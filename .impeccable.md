# BuildersPlatform — Impeccable Design Context

## Design Context

### Users
Spanish-speaking builders/coders (primary MX, LATAM) who want to ship real projects, not consume tutorials. Context: sitting at desk with coffee, skeptical of bootcamp fluff, want to feel like they're joining an elite builder's club, not a learning platform. Technical fluency: junior-to-intermediate engineers. Bilingual: landing/marketing in Spanish, workspace can be EN.

### Brand Personality
Three words: **sharp, confident, crafted**.

- Not: friendly, approachable, playful, cozy, corporate.
- Yes: decisive, refined, opinionated, a little intimidating in a "respect earned" way.
- Emotional goal: "damn, these people take this seriously." Confidence bordering on swagger. Founder energy — this was made by one person who cares, not a template shop.

### Aesthetic Direction
**Refined dark with blood-red punctuation.** Apple/Anthropic structural restraint crossed with startup edge. Editorial typography, generous negative space on marketing, dense information architecture on platform screens. Red is SCARCE — CTAs, accents, live status. Overuse kills it.

References in spirit:
- Anthropic (restraint, serif headings, generous whitespace)
- Linear (dense info, purposeful color, refined dark)
- Vercel (confident CTAs, minimal decoration)
- Rauno Freiberg personal site (precision, small intentional motion)

Anti-references (explicit BANS):
- Bootcamp sites (Platzi, freeCodeCamp, Codecademy) — do NOT look like a course platform
- Generic SaaS landing (stripe-style "feature triptych grid + gradient hero")
- Glassmorphism, blur-heavy cards, neon gradient CTAs
- Rounded-corner-icon-above-heading feature cards
- Purple-blue gradients, cyan accents, "AI startup aesthetic"
- Border-left accent stripes on cards (banned by impeccable)
- Gradient text (banned by impeccable)

### Design Tokens (locked — see globals.css)
```
bg:          #131111   (near-black, slight red warmth)
surface:     #0c0a0a
surface-alt: #171515
border:      #2a2727
primary:     #ff0000   (blood red — USE SPARINGLY)
text:        #ffffff
text-muted:  #9a9a9a
text-dim:    #8a8a8a

font-sans:  Sora         (UI, body)
font-serif: Bodoni Moda  (editorial headings, marketing)
font-mono:  JetBrains Mono
```

Theme: **dark only**. Not user-toggleable. Dark is the brand.

### Design Principles
1. **Scarcity of red.** One red element per viewport on marketing. On platform screens, red = live/active/primary action only. Muted UI by default — when red appears it MEANS something.
2. **Editorial over product.** Marketing pages lean magazine: serif display type, asymmetric compositions, generous line-height on body, long captions with leading numbers over cute icons.
3. **Density where it matters.** Workspace and courses screens are INFORMATION-DENSE, not airy. Developers want to see more at once, not scroll through padding. Marketing is the opposite.
4. **Motion is a scalpel.** One orchestrated entrance per page. Hover states are subtle opacity/color shifts, not transforms. No bounce, no elastic. Exponential ease-out only.
5. **No card template.** No `icon + heading + paragraph` triptych grids. No identical feature cards. Every section earns its layout.

### Technical Constraints
- Next.js 16 (breaking from 14/15 — check node_modules/next/dist/docs before writing)
- React 19
- Tailwind v4 (theme via @theme block in globals.css)
- Dark theme only, no `dark:` variants needed
- Fonts loaded via next/font or CDN — verify in layout.tsx
- Backend: FastAPI on :8000 (see BACKEND_CHANGES.md for endpoints)

### Accessibility
- WCAG AA contrast minimum
- focus-visible red ring at 2px offset 2px (already in globals.css)
- prefers-reduced-motion respected for all transitions
- Keyboard-navigable editor in workspace
